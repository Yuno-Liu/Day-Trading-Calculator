# 台股當沖 / 融資融券計算機 (Taiwan Stock Day Trading & Margin Calculator)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![React 18](https://img.shields.io/badge/React-18-blue)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3-38B2AC)](https://tailwindcss.com/)

專為台灣股市設計的**現股當沖、非當沖、融資與融券信用交易損益計算機**。內建台股完整升降檔位規則（Tick Size）、手續費折讓、證交稅率、融資利息、融券借券費與擔保品利息收入，並自動試算**損益兩平價**、**130% 斷頭追繳線**、**上下檔位價格階梯**及**目標投報率反推掛價**。

---

## ✨ 核心特色與功能

### 1. 完整交易模式支援
* **現股當沖**：適用當日沖銷降稅優惠（個股證交稅千分之 1.5，ETF 千分之 1.0）。
* **現股非當沖**：一般現股買賣（個股證交稅千分之 3.0，ETF 千分之 1.0）。
* **融資買進 (做多)**：
  * 自備款成數預設 **40%**（融資成數 60%），支援快捷切換（40% 上市標準、50% 上櫃/特定、30% 等）。
  * 融資年利率預設 **4.0%**，支援自訂利率與快捷切換（4.0%、4.5%、6.0%、6.5%）。
  * 融資天數預設 **30 天**，支援當日沖銷（0天）、7天、30天、60天、90天、180天。
  * 嚴格遵循券商實務：**融資金額採千元整數無條件捨去**。
  * 自動計算**融資利息**與**進場自備款實付總額**（自備款本金 + 買進手續費）。
* **融券賣出 (做空)**：
  * 保證金成數預設 **90%**（採百元為單位向上進位），支援 100% 全額保證金。
  * 融券天數預設 **30 天**。
  * 借券手續費率預設 **0.08%**（萬分之八），擔保品年利率預設 **0.1%**。
  * 完整試算融券擔保價款、借券手續費支出與保證金利息收益。

---

### 2. 信用交易維持率與 130% 追繳警示線
* **融資維持率與追繳價**：
  * 進場維持率：`成交總額 / 融資金額 × 100%`
  * 130% 追繳臨界價：自動計算市價跌破追繳線時的每股價格與安全跌幅。
* **融券維持率與追繳價**：
  * 進場維持率：`(保證金 + 擔保款) / 成交總額 × 100%`
  * 130% 追繳臨界價：自動計算市價漲破追繳線時的每股價格與安全漲幅。
* 若自訂出場價格跌破（融資）或漲破（融券）130% 追繳線，即時標記醒目紅字警示。

---

### 3. 進出場交易明細完整拆解
* **進場交易明細**：成交總額、自備款/保證金、融資金額/擔保款、進場手續費、證交稅、實付總額與進場維持率。
* **出場交易明細**：
  * 出場成交總額、出場手續費、出場證交稅。
  * 融資償還金額與融資利息支出。
  * 融券借券手續費與擔保品利息收入。
  * 出場結算應收退款（交割入帳款）與預估淨損益。
  * 實質自備款投資報酬率（槓桿 ROI）與名目股價漲跌幅。

---

### 4. 精準損益兩平價與價格階梯
* **損益兩平價反推**：將來回雙向手續費、證交稅、融資利息或借券費納入二分逼近，計算出符合台股跳動單位的精確兩平掛價與跳動檔數。
* **上下檔位價格階梯 (Price Ladder)**：以進場價為中心展開上下十檔（可自訂向上/向下展開更多檔位），即時呈現每檔的費用、預估損益、自備款報酬率與維持率。
* **目標淨利率與停損試算**：
  * 目標淨利率表：依自備款實質投報率反推理論價與最佳可掛價。
  * 停損參考價：依設定之停損金額反推停損出場價位。

## 📊 台股升降單位規則 (Tick Rules)

系統嚴格遵循臺灣證券交易所及中華民國證券櫃檯買賣中心之升降單位規範：

| 股價區間 (TWD) | 升降單位 (Tick Size) |
| :--- | :--- |
| **未滿 10 元** | 0.01 元 |
| **10 元 至未滿 50 元** | 0.05 元 |
| **50 元 至未滿 100 元** | 0.10 元 |
| **100 元 至未滿 500 元** | 0.50 元 |
| **500 元 至未滿 1,000 元** | 1.00 元 |
| **1,000 元 以上** | 5.00 元 |

*註：ETF 未滿 50 元為 0.01 元，50 元以上為 0.05 元。*

## 🚀 快速開始

### 本地直接執行
1. Clone 專案至本地端：
   ```bash
   git clone https://github.com/Yuno-Liu/Day-Trading-Calculator.git
   ```
2. 直接使用瀏覽器打開 `index.html` 即可立即使用。

### 啟用 GitHub Pages 線上使用
1. 進入 GitHub 專案的 **Settings** > **Pages**。
2. 在 **Branch** 選取 `main` 分支並選擇 `/ (root)`。
3. 點擊 **Save**，即可透過 GitHub Pages 網址線上使用！
