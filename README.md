# 台股當沖 / 融資融券計算機 (Taiwan Stock Day Trading & Margin Calculator)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/license/mit)
[![React 18](https://img.shields.io/badge/React-18.3.1-blue)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4.17-38B2AC)](https://tailwindcss.com/)

專為台灣股市設計的**現股當沖、現股（非當沖）、融資、融券與資券當沖損益計算機**。內建台股升降單位（Tick Size）、漲跌停、手續費折讓（即時折讓／月退）、證交稅（依商品、交易模式與交易日期自動判斷）、融資利息、融券手續費與擔保品利息收入，並試算**損益兩平價**、**130% 追繳價**、**目標淨利率反推掛價**、**停損價**及**上下檔位價格階梯**。

所有金額以整數元計算，「金額 × 費率」的取整一律用 BigInt 精確有理數運算，不會出現浮點誤差造成的少 1,000 元、多跳一檔或「−0」。法規資料基準日：**2026-11-06**；計算引擎版本 **2.0.0**。

## ✨ 核心特色與功能

### 1. 交易模式

畫面上以一組「交易類型」切換 5 種模式；只有現股當沖與資券當沖會再出現「方向」切換。不合法的組合（例如現股非當沖做空）引擎會直接拒絕，不會硬算。

| 模式 | 方向 | 進場 → 出場 | 證交稅（個股／ETF） | 計息 | 報酬率分母 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **現股當沖** | 先買後賣／先賣後買 | 現款買進 → 現券賣出（或反向），同日相抵、差額交割 | 0.15%（2017-04-28 至 2027-12-31）／0.1% | 無 | 先買：進場成本；先賣：進場淨收入 |
| **現股**（非當沖） | 只能買進 | 現款買進 → 日後現券賣出 | 0.3%／0.1% | 無 | 進場成本 |
| **融資** | 只能做多 | 融資買進 → 融資賣出 | 0.3%／0.1%（**0 天也一樣**；依出場日判斷） | 融資利息（支出） | 自備款＋進場手續費（自備款報酬率） |
| **融券** | 只能做空 | 融券賣出 → 融券買進 | 0.3%／0.1%（**0 天也一樣**） | 融券利息（收入） | 保證金（保證金報酬率） |
| **資券當沖** | 資買券賣／券賣資買 | 同日融資買進與融券賣出相抵、差額交割 | 0.3%／0.1% | 相抵部分不計息 | 資買：進場成本；券賣：進場淨收入 |

* **商品**：個股（含 TDR）、ETF（含 ETN、槓桿／反向、主動式，以及槓反或主動式債券 ETF）、債券ETF（被動式、非槓反）。
  * **REITs**：請選「ETF」（升降單位相同），並在「進階」把證交稅率覆寫為 0%。
  * **TDR**：請選「個股」，並在「進階」把證交稅率覆寫為 0.1%。
* **現股當沖**：先賣後買會提示券差風險（借券費上限為賣出當日收盤價 7%），以及處置股、變更交易方法股票不得當沖。
* **融資**：
  * 自備款成數預設 **40%**（法定最高融資 6 成，上市、上櫃相同），快捷 40／50／60／100%。低於 40% 會被調整為 40% 並提示，可一鍵套用；個股可能被調降成數，所以允許輸入更高的自備成數。
  * 融資年利率預設 **6.45%**，快捷 6.25／6.35／6.45／6.5%。
  * 融資天數預設 **30 天**，快捷 0／7／30／60／90／180 天；超過 180 天會提示信用期限（6 個月，可展延 2 次）。
  * **融資金額千元以下無條件捨去**；進場應付＝自備款＋買進手續費。
  * 自備 100% 或融資金額被捨為 0 時，顯示「未動用融資」，不計利息，也不顯示維持率與追繳價。
  * **出場證交稅依出場日判斷**：證交稅在融資賣出時收取，出場日＝交易日期＋融資天數（日曆日，不考慮休市）。若出場日與交易日期落在不同的稅率規則（例如債券ETF 停徵期限 2026-12-31 前買進、之後賣出），會以出場日的稅率計算並警示，條件卡也會顯示「證交稅依出場日 YYYY-MM-DD 判斷」。
* **融券**：
  * 保證金成數**欄位空白＝依交易日期自動帶入法定最低值**：2026-11-08 以前為 90%，**2026-11-09 起為 130%**（見規則表）。自行輸入時：
    * 低於常態法定最低 **90%**：以 90% 計算並提示。
    * 介於 90% 與當日最低值之間（例如 2026-11-09 起輸入 100%）：**照輸入值計算**，並警示「低於最低融券保證金成數 130%（金管會臨時穩定措施）；除非措施已解除，券商不會接受此成數」。130% 是未定結束日的臨時措施，若金管會已解除，可直接輸入 90。
    * 等於或高於當日最低值：照輸入值計算，不提示。
  * **保證金百元以下進位**。
  * 融券手續費率預設 **0.08%**（快捷 0.08／0.1%），**於融券賣出時自價款扣除**。
  * **「融券手續費」與「融券費」不同**：0.08% 那筆是融券手續費。券源為借入券或自有券時，券商改收「融券費」（年利率上限 16%，雙方議定），本計算機未計入。
  * 擔保價款＝賣出價款 − 手續費 − 證交稅 − 融券手續費。**進場時投資人只需繳保證金**，費稅已從價款扣除，不會重複計算。
  * 擔保品年利率預設 **0.2%**（快捷 0.1／0.2%），利息收入＝（保證金＋擔保價款）× 年利率 × 天數 ÷ 365。
* **資券當沖**：融券賣出那一邊收融券手續費；證交稅依信用交易 0.3%（ETF 0.1%）；需事先簽署資券相抵同意書。

### 2. 信用交易維持率與 130% 追繳價
* **融資維持率**：`市值 ÷ 融資金額 × 100%`。追繳價為維持率仍 ≥ 130% 的最低合法檔位，收盤低於此價即追繳。
* **融券維持率**：`(擔保價款 + 保證金) ÷ 市值 × 100%`。追繳價為維持率仍 ≥ 130% 的最高合法檔位，收盤高於此價即追繳。
* 維持率以 BigInt 精確計算，並**向下截斷到 0.01%**（不四捨五入），所以畫面顯示與追繳判斷一致：顯示 129.99% 一定低於 130%，顯示 130.00% 一定不追繳；剛好落在追繳價時不會誤報。
* 自訂出場價的維持率低於 130% 時，用文字加警示圖示標示，不只靠顏色。
* 「追繳價」是追繳門檻，不是斷頭價：整戶低於 130% 時須於 2 個營業日內補繳，逾期才於次一營業日起處分；整戶回到 166% 以上解除。本計算機假設帳戶只有這一筆部位。

### 3. 進出場交易明細完整拆解
* **進場明細**：成交金額、融資金額／自備款或融券保證金／擔保價款、手續費（月退制顯示「交割收 X、次月退 Y」）、證交稅、融券手續費、進場應付或進場實收、報酬率分母、進場維持率。
* **出場明細**（有自訂出場價時用該價，否則以兩平價為參考）：
  * 成交金額、手續費、證交稅、融券手續費。
  * 償還融資與融資利息，或融券利息收入。
  * 融券與資券當沖另列「退還保證金＋擔保價款」與「與進場相抵」，交割金額可以對得起來。
  * 交割應收／應付（負數＝需補繳，加警示圖示）、來回總成本、淨損益、報酬率（依模式標示為自備款報酬率／保證金報酬率／報酬率）與價差報酬率（依方向計算的價格變動，不含費用與槓桿）、出場維持率。報酬率分母不大於 0 時，會說明報酬率無法計算的原因。
  * 月退制另列退款金額：交割依原價收取，損益已扣除退款。
* **費率與條件**：有效手續費率、證交稅率（依商品、模式、日期動態顯示；債券ETF 融資且出場日不同於交易日期時，另列稅率判斷日）、信用條件、總股數、交易日期、漲停／跌停、融券最低成數及下一期變動。

### 4. 損益兩平價、目標價、停損價與價格階梯
* **損益兩平價**：把來回手續費、證交稅、融資利息或融券手續費／利息收入都納入，先以公式估計理論價，再逐檔修正，以整數損益比較，找出「淨損益 ≥ 0 且最接近進場價」的合法掛價，並顯示「需上漲 N 檔」「需下跌 N 檔」或「原價即兩平」與漲跌幅。費用高於該方向所有可能獲利時顯示「無法達成」。有參考價且兩平價超出漲跌停時，摘要卡與進場價下方都會加上「超出漲跌停」標記（文字＋圖示），並在提醒中列出漲停、跌停價。
* **目標價**：預設目標淨利率 `3, 2.5, 2, 1, 0, -1, -2`（%），可在「進階」自訂，最多 12 項，依各模式的報酬率分母計算。點列可展開理論價、實際淨利率與來回總成本，並可一鍵設為出場價；不可達顯示「無法達成」，超出漲跌停會標示。
* **停損價**：輸入可承受的最大淨虧損金額，反推停損出場價；金額大於最大可能虧損時提示無對應價。停損價超出漲跌停時，同樣標示「超出漲跌停」並提醒。
* **價格階梯**：以進場價為中心預設上下各 10 檔，可「向上 +5 檔」「向下 +5 檔」，展開後可「重設」；跌到 0.01 停止。每列顯示價格、檔數、漲跌幅、總成本、損益、報酬率，信用模式加維持率；標示進場、兩平、追繳、漲停、跌停、超出漲跌停與目前出場價。**點任一列即帶入出場價**。
* **輸入旁即時結果**：進場價下方顯示兩平價與追繳價，出場價下方顯示淨損益、報酬率與維持率，停損金額下方顯示停損價。
* **±1 檔按鈕**：進場價、出場價左右各有 −／＋ 按鈕，依該價位所在級距的升降單位跳動；出場價空白時以進場價為起點；到 0.01 時提示「已是最低價 0.01」，超過價格上限時提示「已達價格上限 100,000 元」。張數也有 −／＋。
* **輸入容錯**：接受全形數字、千分位逗號、「2.8 折」寫法。千分位必須是正確格式（例如 `1,000`、`1,000.5`）；`43,45` 這類寫法視為格式不正確，不會被當成 4345。價格不在合法檔位、自備成數或保證金成數被調整、張數非整數時，欄位旁提示並可一鍵套用。

## 📈 漲跌停

在「進階」輸入參考價（昨收）後，計算機會算出漲停與跌停價，並在目標價、價格階梯、自訂出場價中標示超出範圍的價格。

* **漲停**：不超過「參考價 ×（1 + 幅度）」的最大合法檔位；**跌停**：不低於「參考價 ×（1 − 幅度）」的最小合法檔位。
* 是否為合法檔位，依計算出的價格本身所在級距判斷。例：參考價 45.6 → 50.16 只能取 50.1（50 元以上級距為 0.1 元）。
* 幅度不足一檔時以一檔計，價格最低 0.01。
* 證交所官方範例：參考價 40.60 → 漲停 44.65、跌停 36.55（已列入測試）。
* 幅度可選 **10%（一般）／20%（2 倍槓反）／無限制**。新上市前 5 日、含國外成分的 ETF 等沒有漲跌幅的標的，請選「無限制」。
* 未輸入參考價時不檢查漲跌停；參考價無法辨識、≤ 0 或超過 100,000 元時會提示並忽略漲跌停計算。

## 📱 手機與 iOS

* **手機優先版面**：手機上由上而下是交易設定、價格與數量、費用設定、信用參數、進階、試算結果；結果以「明細／目標價／價格階梯」分頁。桌機（≥ 1024px）左欄輸入固定、右欄結果全部展開。
* **底部摘要列**：手機上有結果、且摘要卡不在畫面上時，底部會出現玻璃材質的摘要列，顯示兩平價與淨損益／報酬率（或追繳價／維持率），報酬率標籤依模式顯示為自備款報酬率／保證金報酬率／報酬率，點一下捲回結果區；已處理安全區域（瀏海、Home 指示條）。手機橫向等矮視窗（高度 ≤ 500px）時改為精簡單列，保留可用內容高度。
* **「今日」自動更新**：交易日期空白＝台北今日。跨過台北午夜、App 回到前景（從背景切回、頁面重新顯示或取得焦點）時會更新「今日」，計算結果與依日期的提示（例如 2026-11-09 起融券最低 130%）都跟著更新，不必重新整理。
* **加入主畫面**：在 iOS Safari 開啟、尚未加入主畫面時，會顯示一次「加入主畫面」提示（分享 →「加入主畫面」），可關閉，關閉後不再顯示。以主畫面 App 開啟時，頂部有實色狀態列底板，並會要求瀏覽器持久保存設定。
* **離線使用**：**只有以 http/https 開啟（例如 GitHub Pages）並在連網狀態下完整載入過一次之後**才能離線使用；此時會註冊 Service Worker，快取頁面、圖示與 4 個鎖版 CDN 檔。直接雙擊 `index.html`（file://）時不會註冊 Service Worker，也不會掛上 manifest，**每次開啟都需要連網**載入 CDN。CDN 無法載入時，畫面會顯示「需要網路連線載入元件」與「重新載入」按鈕。
  * CDN 檔只快取驗證過狀態碼的成功回應，CDN 暫時出錯不會被存進快取。Tailwind CDN 不支援 CORS，只能以無法驗證狀態的 opaque 回應快取。由於網址已鎖定版本、內容不會變，快取命中後**不會再重新抓取**（平時零額外流量）；若曾快取到錯誤內容，頁面載入後偵測到對應元件缺失，會請 Service Worker 清除該筆快取並自動重新載入一次（同一分頁只嘗試一次，離線時不嘗試）。
* **深色模式**：跟隨系統的淺色／深色設定；紅漲綠跌的語意在兩種模式下都保留，漲跌價格旁另有 ▲／▼，不只靠顏色。
* **觸覺回饋（漸進增強）**：在支援的 iOS Safari 上，點 Segmented、±1 檔與張數按鈕、價格階梯列時會有輕微震動。不支援的瀏覽器沒有任何影響，鍵盤與螢幕閱讀器操作也不受影響。
* **其他**：支援減少動態效果與降低透明度設定；Segmented 可用方向鍵切換；所有輸入欄位字級 ≥ 16px，避免 iOS 自動放大。

## 💾 設定記憶與分享

* **自動記憶**：所有輸入、展開的區塊、目前分頁及已關閉的提示，會存在瀏覽器的 `localStorage`（鍵名 `twcalc:v2`）。私密瀏覽或無法存取時不影響計算。主畫面 App 與 Safari 的設定分開保存。
* **重設**：右上角「更多選項」→「重設為預設值…」，確認後才會清除。
* **分享**：點右上角分享鈕：
  * 以 http/https 開啟時，使用系統分享（`navigator.share`），內容包含試算摘要文字與帶有 `#` 狀態參數的連結；不支援時改為複製。
  * **連結一律帶交易日期**（實際使用的日期；欄位空白時帶當天日期），摘要文字也會列出交易日期，收件者在其他日期開啟仍得到相同結果。
  * 以 file:// 開啟時，只複製試算摘要文字（不含連結）。
  * 無法自動複製時，會跳出文字框讓你手動複製。
* **開啟分享連結**：連結中的設定會套用到欄位，原本的設定會另存在 `localStorage`，可按「還原我的設定」換回來，或「保留連結設定」。做出選擇之前重新整理頁面，橫幅與還原仍然可用；連續開啟多條連結時，保留的是最初的原設定。套用後網址中的 `#` 參數會被移除，之後一般操作不會改動網址。App 已開著時再貼上分享連結也會套用。
* **格式檢查**：從連結或 `localStorage` 還原的每個欄位都會檢查格式（數值欄位只接受數字與常用符號、日期須為 `YYYY-MM-DD`、選項須為合法值，並移除 Unicode 雙向控制字元），不合格的欄位會被忽略。

## 🛠️ 技術架構

* **前端框架**：React 18.3.1（UMD）＋ Babel standalone 8.1.1（瀏覽器端即時轉譯 JSX）。
* **樣式工具**：Tailwind CSS 3.4.17（CDN）＋ 內嵌 CSS 設計 token（淺色／深色兩組）。
* **CDN 一律鎖精確版本**，不使用浮動版本。
* **架構特色**：單一 HTML 檔案，下載即可雙擊開啟。`index.html` 內分成：
  1. `<script id="tw-calc-engine">`：純 JavaScript 計算引擎 `TWCalc`（不依賴 DOM 或 React），可在瀏覽器與 Node 中執行。
  2. `<script type="text/babel">`：React UI，只透過 `TWCalc` API 取值。
  3. Service Worker 註冊（只在 http/https）。
* **PWA 檔案**：`manifest.webmanifest`、`sw.js`（快取名稱 `twcalc-v2.0.0`；導覽請求 network-first，3 秒逾時退回快取；鎖版 CDN cache-first，只存經 CORS 驗證的成功回應，無法 CORS 的 Tailwind 才存 opaque，命中後不重抓；頁面偵測到 CDN 元件缺失時以 `CDN_PURGE` 訊息請 SW 清除該筆快取後重新載入；同源靜態檔 stale-while-revalidate）、`icons/`。

## 🚧 未建模項目與限制

* **未納入計算**：融券除權息強制回補與股利支付；標借費、議借費、借券費；處置股保證金加成；整戶擔保品抵繳與多部位整戶維持率；零股交易。
* **單一部位假設**：維持率與追繳價只看這一筆部位；實際以整戶維持率計算。
* **天數須自行輸入**：融資、融券計息天數由使用者輸入，不會依交易日曆自動推算交割日；融資出場日（用來判斷出場證交稅率）也只以「交易日期＋天數」的日曆日推算，不考慮休市。
* **融券費未計入**：券源為借入券或自有券時券商收取的「融券費」（年利率上限 16%，雙方議定）不在計算範圍內。
* **月退制為逐筆近似**：實際退款通常以當月合計計算，與逐筆計算可能有幾元差異。
* **取整方式未有法規依據的項目**：證交稅尾數（預設捨去）、融資利息、融券手續費、融券利息（四捨五入），每筆差異不超過 1 元。
* **商品分類**：REITs 請選「ETF」並把證交稅率覆寫為 0%；TDR 請選「個股」並覆寫為 0.1%；槓反或主動式債券 ETF 請選「ETF」。
* **待確認法規**：債券 ETF 停徵延長案尚未三讀；融券保證金 130% 未定結束日；現股當沖降稅 2027 年後是否延長；千金股 1 元升降單位尚未核定；櫃買中心漲跌停取整沒有官方範例，推定與上市相同。法規變動時需要更新程式。
* **輸入範圍**：價格 0.01 ～ 100,000 元；張數 1 ～ 100,000 張（只支援整張）。
* **需要網路**：首次開啟需從 CDN 載入 React、Babel 與 Tailwind，並在瀏覽器端即時轉譯，低階手機或慢速網路下首次載入較慢。以 file:// 開啟時沒有離線快取，每次都需要網路。

* 目標價、停損、兩平價不可達時明確顯示「無法達成」，不再顯示 0.01。
* 檔數計算不再於 50,000 檔截斷；價格階梯 ±2,000 檔在 300ms 內完成。
* 維持率改為向下截斷到 0.01%，顯示值與是否追繳的判斷一致（不再出現顯示 130.00% 卻追繳）。
* 融資出場證交稅改依出場日（交易日期＋融資天數）判斷，跨越稅率規則邊界時警示。
* 債券ETF 停徵期間修正為 2017-01-01～2026-12-31，之前的日期以 0.1% 計。
* 千分位逗號須為正確格式，`43,45` 不再被當成 4345。
* 參考價無法辨識、≤ 0 或超過 100,000 元時，漲跌停計算回傳 null，不會拋出例外。

**規則與預設值**
